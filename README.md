# Análise de Dados: População e Demografia

## Objetivo
Este projeto analisa dados de população e demografia para entender os fatores que influenciam o crescimento populacional em diferentes regiões do mundo. Usando técnicas de análise de dados, exploramos como natalidade, mortalidade e migração impactam o crescimento populacional. O objetivo é fornecer insights que possam auxiliar no planejamento urbano e políticas públicas.

## Estrutura do Repositório

- **Capa/**: Dados pessoais dos integrantes do grupo (Nome, RA).
- **Sumário/**: Descrição dos principais itens e etapas do projeto.
- **Projeto/**: Contém os dados principais e os scripts de análise do projeto.
- **Figuras/**: Imagens geradas durante a análise, como gráficos e diagramas (ex.: Figura 1, Figura 2).
- **Tabelas/**: Tabelas organizadas com dados verificados e utilizados nas análises.

## Principais Resultados
- **Tendência de Crescimento**: Países em desenvolvimento apresentam um crescimento populacional mais acelerado.
- **Impacto da Urbanização**: A urbanização está fortemente ligada ao aumento populacional, especialmente em áreas metropolitanas.
